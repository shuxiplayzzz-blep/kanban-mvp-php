# Kanban MVP (PHP + MySQL + JS)

Prosta aplikacja webowa do zarządzania projektami i zadaniami w stylu tablicy Kanban, napisana w czystym, strukturalnym PHP (PDO) z wykorzystaniem Bootstrap 5 oraz asynchronicznych zapytań `fetch()`.

## Uruchomienie lokalne
1. Zaimportuj schemat bazy danych z pliku `database.sql` do MySQL.
2. Skopiuj plik `config.example.php` jako `config.php` i uzupełnij dane dostępowe do bazy danych.
3. Uruchom projekt na serwerze lokalnym (np. XAMPP / Laragon).
